## Gameplay and real-schematic audit (2026-10-06)

`scripts/run-local-gameplay-audit.ps1` creates separate creative flat test worlds, runs development-only Java probes on the Minecraft client thread, and shuts each client down normally. Probe classes are outside the distributed JARs. It exercises the native `ClientJob`, placement oracle, action gateway, server update notifications, and optional source-mod APIs.

```powershell
.\gradlew.bat formatAll check buildAll :planning-core:officialTest
.\scripts\run-local-gameplay-audit.ps1 `
  -Targets fabric-26.2,fabric-26.3,neoforge-26.2,neoforge-26.3,litematica-fabric-26.2,litematica-fabric-26.3,forgematica-neoforge-26.2 `
  -JavaHome 'C:/Program Files/Java/jdk-25.0.2' `
  -SchematicsDirectory 'E:/Games/Minecraft/prism/instances/Vanilla_Latest/.minecraft/schematics'
```

The schematic argument is optional. The script recursively records source-file sizes, modification ticks and SHA-256 before launch, then verifies them again even if a probe fails. The probe only calls source-mod read APIs and creates unsaved in-memory placements; it never saves, modifies or deletes fixtures. Logs, results and before/after evidence are ignored local artifacts under `build/gameplay-audit/<timestamp>`. Each child launch uses a separate single-use Gradle process and a timeout. The agent records the game PID and start time; timeout cleanup checks both plus the unique agent/output launch arguments before stopping the owned client, then stops the owned helper tree. Do not run other Gradle builds concurrently against the same output directories.

A seven-target run at `20261006-175211-170` passed all the following cases:

- All three bridges: 53 real `.litematic` files loaded read-only; 5,300 sampled palette cells per bridge covered 171 native states. Twelve rotated/mirrored placement previews per bridge checked 724 exact target cells against the native schematic world. ## 0.0.3 unsupported or conservative behavior (historical)

The placement oracle covers ordinary hotbar `BlockItem` placement, layered snow, repeater delay interaction, and ordinary block breaking. It does not model arbitrary modded placement, entity actions, redstone evolution, gravity, waterlogging transitions or multi-block effects. Dry breaking can be predicted as air, but fluid-containing blocks and directly coupled multi-block structures defer before breaking. Destructive exact replacement currently requires a verifiable plain property-free block on a plain full-block support; property-sensitive targets retain predictable non-breaking interactions and defer unverified break fallback. The schematic bridges report any overlapping subregions as a conflict, including overlaps whose target states may be identical. Reported metadata revisions invalidate frozen sessions, but direct source-container edits that do not advance those markers are not guaranteed to be detected. Query and preview are bounded partial reads, not full-domain aggregate results. These gaps prevent claiming complete 26.2/26.3 acceptance.
