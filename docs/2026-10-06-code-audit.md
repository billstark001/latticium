## 修复的行为问题

- 客户端 `ClientLevel.hasChunk` 不能证明区块已加载。主模组和三个桥接改用实际区块缓存查询，避免把未加载位置当作已知空气；新增检查防止重新引入该调用。
- 替换任务在确认破坏之后，不再因为原始选择谓词变成 false 而丢弃候选和冻结目标。后续动作仍检查最后确认的状态，且破坏前保留两次动作的预算。
- 快速替换先验证普通无属性方块的破坏后放置，再选择目标和允许破坏。缺少可验证支撑、属性敏感目标、含水方块以及直接耦合的多方块结构在破坏前延期。
- 快速填充同时识别普通空气、洞穴空气和虚空空气。
- 标签更新推进注册表版本，停止使用旧绑定的任务并重新绑定自动配置；已发送的动作继续等待确认。退出世界、关闭或取消网关后拒绝新动作。
- 蓝图会话只建立一次，重复枚举不能授权另一个放置；子区域迭代顺序不会误判变更。共享会话元数据使用弱引用，避免保留已退出的世界或已移除放置。
- 命名选区快照复制内部列表，防止调用者修改正在运行的任务。刷新依赖读取展开后的函数和声明，不再遗漏间接世界事实。
- 假想状态的规则检查不再复用同一维度中可能因变化失效的远处光照、流体和实体性事实。
- 原生状态解码直接解析完整的规范属性，拒绝缺失、多余、非法和非规范拼写，不再枚举方块的所有状态。
- 本地世界配置以规范保存目录为身份，避免同名世界互相覆盖；拒绝损坏的选区尾项和规范化之后重复的离线目录标识。

## 设计与性能改进

- `Compiler.Bound` 携带冻结的事实依赖及每列空间偏移。扫描、规划和材料检查分别请求所需列；无法证明局部性的扩展保持保守的有界 halo。
- 原生捕获使用不可变稠密 `FactWindow`、紧凑状态复用与空间列掩码。坐标谓词不读取世界或目标；候选规划捕获局部窗口。直接状态依赖不会因为声明较大半径而读取整个立方体。
- 可选 `TargetSlice` 与逐点读取共享会话和目标语义，不支持或无效时回退。三个蓝图桥接复用 `BlueprintSnapshots` 的身份、边界和重叠逻辑。
- 连续 `adjacent` 对可达偏移去重，消除指数重复读取；混合空间表达式使用单次求值图记忆和硬预算。坐标溢出与预算耗尽保持 Unknown。
- 有限范围支持平移和邻接范围推导，去重边界并限制交集、分组工作；重叠扫描范围先合并掩码，每个覆盖单元只求值一次。
- 纯规划器增加可恢复的 `Search.advance`，在冻结输入上保存 Dijkstra 搜索进度，限制状态/队列数量。原生任务仍同步规划，尚未建立跨 tick 的完整输入租约。
- 提取符号注册表、蓝图注册集合、材料门控、选择快照和规则状态覆盖等复用模块，保持现有模块边界。

本地状态捕获分配约 36–39 KB/section，原来的 map 实现约 715 KB/section。该结果只代表记录中的开发环境。宽泛的旧接口或自定义依赖仍可能读取 48³ 单元并超过一帧预算。
