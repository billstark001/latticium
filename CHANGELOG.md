# Changelog

All notable changes to Latticium are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html). The single source for the mod version is `mod_version` in `gradle.properties`. Entries remain under Unreleased until a release is tagged.

## [Unreleased]

### Added

- Native task controls and a diagnostic page, with rebindable controls and a small task HUD.
- Shared Cloth Config / AutoConfig settings, bundled for Fabric and NeoForge.
- Optional Fabric Mod Menu integration and a NeoForge built-in mod-list settings entry.
- English, Simplified Chinese, Traditional Chinese, and Japanese UI translations.
- Stop-all control that cancels the current task and suspends automatic activation until restored.
- Finite fill, replace, and clear jobs with client commands, saved selections, and schema-1 profiles.
- Typed, read-only DSL with bounded section queries, profile preview, and opt-in activation.
- Optional Litematica bridges for Fabric 26.2/26.3 and a Forgematica bridge for NeoForge 26.2.
- Continuous job refresh, manual refresh mode, and `/latticium refresh`.
- CI and release assembly for four main mods and three optional bridges.

### Changed

- Bumped the development version to 0.0.2.
- Exposed immutable client/job snapshots for UI consumers, keeping partial scans, pending confirmations, continuous monitoring, and action-budget exhaustion distinct.
- Fabric development runs are generated by Loom and use Gradle's Java 25 launcher.

### Fixed

- Client launch tasks no longer inherit an unintended Java 21 runtime from local IDEA settings.
